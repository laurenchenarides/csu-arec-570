Cereal Demand Demo

AREC 570 / ECON 530 · Lecture 6.2

Author

Lauren Chenarides

This demo estimates demand for ready-to-eat cereal in steps, then uses the estimates to simulate a merger. It goes with the BLP section of Lecture 6.2. Each step shows the code, the output, and how to read the result.

To run it yourself, install the packages once and run the script, which takes under a minute on a laptop:

pip install pyblp pandas
python cereal-demand-demo.py

Download the full script (cereal-demand-demo.py)

The data

The data are the simulated cereal data from Nevo (2000), which ship with PyBLP (Conlon and Gortmaker 2020). Nevo writes that the data are “not real and should not be used for any analysis,” so the numbers below illustrate the method and say nothing about actual cereal markets.

One row is a product in a market, and a market is a city in a quarter. The file holds 24 products in 94 markets (47 cities in 2 quarters), which gives 2,256 rows. Each row records the market share, the price, two characteristics (sugar content and whether the cereal gets soggy in milk, called mushy), and the instruments from the original paper. A second file holds simulated consumers, with income, age, and an indicator for children.

import numpy as np
import pandas as pd
import pyblp

products = pd.read_csv(pyblp.data.NEVO_PRODUCTS_LOCATION)
agents = pd.read_csv(pyblp.data.NEVO_AGENTS_LOCATION)

Plain logit turns market shares into a linear regression (Berry 1994). The dependent variable is the log share of each product minus the log share of the outside good (buying no cereal):

ln⁡sjt−ln⁡s0t=xjtβ−αpjt+ξjt \ln\, s_{jt} - \ln\, s_{0t} = x_{jt}\beta - \alpha p_{jt} + \xi_{jt} 

outside_share = 1 - products.groupby("market_ids").shares.transform("sum")
y = np.log(products.shares) - np.log(outside_share)

Step 1: plain logit by OLS

This regression treats price as exogenous and controls only for a constant, sugar, and mushy.

X = np.column_stack([np.ones(len(products)), products.prices, products.sugar, products.mushy])
ols_no_fe = np.linalg.lstsq(X, y, rcond=None)[0][1]
Price coefficient: -10.12

Step 2: add product fixed effects

Product fixed effects absorb each product’s fixed quality, which is part of ξjt\xi_{jt}. The comparison is now each product with itself across markets.

price_within = products.prices - products.groupby("product_ids").prices.transform("mean")
y_within = y - y.groupby(products.product_ids).transform("mean")
ols_fe = (price_within @ y_within) / (price_within @ price_within)
Price coefficient: -28.95

The coefficient roughly triples. Better cereals cost more, so in Step 1 a high price partly signals high quality, and the estimate is biased toward zero. This is the omitted-variable problem from Lecture 6.1 in a demand setting.

Step 3: add instruments for price

PyBLP estimates plain logit by instrumental variables, using the instruments from the original paper.

logit_problem = pyblp.Problem(
    pyblp.Formulation("0 + prices", absorb="C(product_ids)"), products
)
logit = logit_problem.solve(method="2s")
Price coefficient: -30.05 (standard error 1.01)

The instruments change the estimate by about 4 percent. That small change is a feature of these simulated data. Instruments address the part of ξjt\xi_{jt} that varies within a product across markets, and in real data that part can be large.

Step 4: add random coefficients

Random coefficients let tastes for price and characteristics vary with income, age, and children, and with traits the researcher does not observe. The model now has no closed-form solution, so PyBLP searches numerically over the taste parameters.

rc_problem = pyblp.Problem(
    (
        pyblp.Formulation("0 + prices", absorb="C(product_ids)"),
        pyblp.Formulation("1 + prices + sugar + mushy"),
    ),
    products,
    pyblp.Formulation("0 + income + income_squared + age + child"),
    agents,
)
rc = rc_problem.solve(
    initial_sigma,
    initial_pi,
    optimization=pyblp.Optimization("bfgs", {"gtol": 1e-5}),
    method="1s",
)

The script defines the starting values initial_sigma and initial_pi.

Mean price coefficient: -62.73 (standard error 14.80)
Optimizer converged after 51 iterations; run time 16 seconds

This matches the “Tighter Tolerance” column of Table 7 in Conlon and Gortmaker (2020). Their table is worth reading alongside this result: with a looser gradient tolerance, the same model on the same data gives a mean price coefficient of -32.4, and their best-practice estimate is -27.5, while the mean own-price elasticity stays between -3.62 and -3.70. Individual coefficients move, so report the optimizer, tolerances, starting values, and integration method in an appendix, along with the quantities that matter for your question.

Step 5: compare the models and simulate a merger

The last step asks what each model implies for substitution, then simulates a merger of firms 1 and 2, the two largest firms in the data (about 75 percent of sales). The simulation recovers each product’s marginal cost from the pricing model, assigns the two firms joint ownership, and solves for new prices.

merged_firms = products.firm_ids.replace(2, 1).to_numpy()
new_prices = results.compute_prices(firm_ids=merged_firms, costs=results.compute_costs())
Plain logit Random coefficients
Median own-price elasticity -3.65 -3.61
Largest rival response ÷ smallest 1.00 6.19
Median price change, merging firms 5.8% 11.6%
Median price change, other firms 0.1% 0.4%
Change in consumer surplus -11.6% -13.6%

The two models agree on own-price elasticities and differ on the merger. The second row explains why. When one product’s price rises, plain logit makes every rival respond in the same proportion, so the ratio is 1. With random coefficients, the most affected rival responds about 6 times as much as the least affected (the median across products, in one market). Merging firms raise prices more when their products are close substitutes, because more of the lost sales stay within the merged firm, and plain logit has no way to represent that closeness.

A counterfactual depends on how the model lets consumers substitute. That is an assumption the section has to state, defend, and vary.
